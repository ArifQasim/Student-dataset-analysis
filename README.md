#Student Dataset Analysis

This is a self-learning project built to practice NumPy by analyzing a student marks dataset.

What this project includes
Random student marks generation using NumPy
Total marks calculation for each student
Average (mean) marks
Median marks
Minimum and maximum marks
Subject-wise analysis
Student-wise analysis
Top-performing students
Pass/Fail analysis using Boolean masking
Ranking students based on total marks
Practice with NumPy arrays, indexing, slicing, statistics, sorting, and logical operations
