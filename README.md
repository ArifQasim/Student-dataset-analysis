# Student Dataset Analysis

This is a **self-learning project** built to practice **NumPy** by analyzing a student marks dataset. The project focuses on applying core NumPy concepts through a real-world dataset analysis workflow.

## Features

* Generate random student marks using NumPy
* Calculate total marks for each student
* Calculate average (mean) marks
* Find median marks
* Find minimum and maximum marks
* Perform subject-wise analysis
* Perform student-wise analysis
* Identify top-performing students
* Count pass/fail students using Boolean masking
* Rank students based on total marks
* Practice indexing, slicing, sorting, statistical operations, and logical operations

## Technologies Used

* Python
* NumPy
* Jupyter Notebook

## Purpose

This project was created as part of my self-learning journey to strengthen my NumPy fundamentals before moving on to data analysis, machine learning, and AI.
